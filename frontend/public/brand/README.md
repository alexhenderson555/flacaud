# FlacAud brand assets

| File | Size | Use |
|------|------|-----|
| `../logo.png` | 512×512 | Site favicon, PWA, sidebar, cover fallback |
| `flacaud-icon.png` | 512×512 | Same mark (source copy) |
| `flacaud-mark.svg` | vector | Favicon SVG, docs, exports |
| `telegram-channel.png` | 512×512 | **Telegram channel** profile photo |
| `telegram-chat.png` | 512×512 | **Telegram bot / support chat** avatar |

## Telegram upload

1. **Channel** → Settings → Edit → Profile photo → upload `telegram-channel.png`
2. **Bot or group chat** → Edit → Profile photo → upload `telegram-chat.png`

Telegram accepts 512×512 PNG; both files are square and safe to crop to circle.

## Colors

- Background: `#08080c`
- Accent: `#2575fc`
- Gradient: `#6a11cb` → `#2575fc`
