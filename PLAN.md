# Multi-source music downloader — план

> Дата: 2026-05-29. Версия плана: 0.1 (черновик).
> Кодовое имя: `tidal-dl-ru` (рабочее, переименуем при ребрендинге).

## 1. Позиционирование

**Кому продаём:** RU-меломаны 20-40 лет, у которых Tidal/Spotify/Apple Music заблокированы или сложны в оплате. Подсегменты:

- **Audiophile-собиратели** — хотят локальную FLAC-библиотеку, ценят теги и обложки
- **Бывшие Spotify-юзеры** — потеряли доступ, хотят сохранить плейлисты в лучшем качестве
- **DJ и продакшен-сцена** — нужно BPM/key и FLAC для миксов
- **Караокщики / эмоциональные слушатели** — синхро-тексты на русском

**УТП (что выделяет от конкурентов):**

1. Lossless FLAC из Tidal, доступный из РФ без VPN
2. Один интерфейс ко многим сервисам (YT Music, SoundCloud, Bandcamp; дальше Spotify-match, Deezer, Apple)
3. **Shazam-режим в TG** — голосовое в бот → FLAC из Tidal. Этого нет ни у одного конкурента
4. Karaoke-режим с переводом текстов на русский
5. Платёжная модель в RU (YooKassa + Tribute) — без бубна с зарубежными картами

## 2. Архитектура целевой системы

```
┌─────────────┐  ┌─────────────┐  ┌─────────────┐
│  Web (RU)   │  │  TG Bot     │  │  CLI        │
│  Vite+React │  │  aiogram 3  │  │  typer      │
└──────┬──────┘  └──────┬──────┘  └──────┬──────┘
       │                │                │
       └──────────┬─────┴───────────┬────┘
                  │                 │
            ┌─────▼─────┐    ┌──────▼──────┐
            │ FastAPI   │    │  CLI core   │
            │ /search   │    │  (как сейчас)│
            │ /download │    └─────────────┘
            │ /me       │
            └─────┬─────┘
                  │
       ┌──────────┼────────────┬─────────────┐
       │          │            │             │
   ┌───▼───┐ ┌────▼────┐  ┌────▼─────┐  ┌────▼─────┐
   │ Redis │ │Postgres │  │  S3-ish  │  │ ARQ      │
   │ queue │ │users,   │  │  tmp     │  │ workers  │
   │       │ │pool,subs│  │  files   │  │ (download│
   └───────┘ └─────────┘  └──────────┘  │  +tag    │
                                        │  +analyze)│
                                        └────┬─────┘
                                             │
                                  ┌──────────┼──────────┐
                                  │          │          │
                              ┌───▼───┐  ┌───▼───┐ ┌────▼────┐
                              │Tidal  │  │yt-dlp │ │ AudD    │
                              │pool   │  │       │ │ (Shazam)│
                              └───────┘  └───────┘ └─────────┘
```

**Слои отвечают:**
- **CLI core** (то что есть сейчас) — провайдеры, скачивание, теги, лирика. Используется и FastAPI, и CLI напрямую.
- **FastAPI** — REST API. `/download` ставит задачу в очередь, возвращает task_id. `/tasks/{id}` для статуса. Файлы выдаются через signed URL с TTL 24 ч.
- **ARQ workers** — асинхронные раннеры. Один воркер = один поток скачивания, чтобы не упираться в один Tidal-аккаунт.
- **TG bot** — самостоятельный процесс, общается с FastAPI HTTP-ом. Принимает URL, голосовые, выдаёт файлы.
- **Pool DB** — таблица `tidal_accounts(id, refresh_token, last_used, downloads_today, status)`. Pool-менеджер выдаёт следующий рабочий аккаунт.

### 3.2 Домены

| Домен | Назначение | Цена | Регистратор |
|-------|------------|------|-------------|
| `tidalru.ru` (или схожее) | Маркетинговый лендинг для RU | ~200₽/год | REG.RU / Beget |

DNS — **Cloudflare**. Тогда даже при RKN-блокировке домена IP остаётся не виден. План миграции на новый домен: уведомление в TG-боте + редирект.

### 3.3 Платежи

| Провайдер | Что покрывает | Комиссия | Риски |
|-----------|---------------|----------|-------|
| **YooKassa** (основной) | Mir, Visa, MC, СБП, ЯД | ~3.5% | Может закрыть мерчанта при жалобах от Tidal/правообладателей |
| **Tribute** (запасной) | Платежи внутри Telegram | 5% TG + 0% Tribute | Менее формальный, сложнее закрыть |
| **Boosty** (donate-стиль) | Подписочный донат | 5% | Если позиционируем как «поддержи проект», нет прямого товара |

Рекомендация: подключить **оба** YooKassa и Tribute на старте. Если YooKassa отвалится — за день переключаемся на Tribute через переменную окружения.

### 3.4 Мониторинг и бэкапы

- **Uptime Kuma** на отдельной VPS-копейке (€3/мес) — пингует API и бот каждую минуту
- **Sentry** free tier — Python exceptions + JS на фронте
- **Loki + Grafana** (или Better Stack для простоты) — логи воркеров
- **Бэкапы** — еженедельно дамп PostgreSQL → B2 + локально на резервный VPS

### 3.5 Безопасность

- root SSH выключен, только ключи
- ufw/fail2ban, открыты только 22, 80, 443
- автоматические unattended-upgrades
- секреты в `.env`, никогда в git; в проде через docker secrets или sops
- **Tidal refresh_token-ы шифруются** Fernet-ключом из env при сохранении в БД

**Себестоимость инфры в стационарном режиме: ~€20/мес (~2000₽)** при отсутствии трафика. С трафиком +€10-20/мес исходящего из Hetzner (он не лимитирован, но платный сверх квоты).

## 4. Пул Tidal-аккаунтов

**Бутылочное горлышко проекта.** Купить Tidal HiFi из РФ напрямую нельзя. Источники для своего пула (в порядке устойчивости):

1. **Family Plan через Sharesub-ам подобных** — €3/мес за слот в семейной подписке. Минус: внезапно могут выкинуть из семьи.
2. **Виртуальные карты иностранных банков** — Wirex, RoamingMan, Pyypl (UAE). $5-10 за карту + комиссия.
3. **Подписки через TR/IN/UA-регионы** — самые дешёвые (~100₽/мес как у вас), но Tidal периодически режет аккаунты по гео.
4. **Друзья за рубежом** — попросить открыть Family Plan и взять слот.

### 4.1 Стратегия ротации

- 1 аккаунт обслуживает **до ~100 треков/день** комфортно
- Свыше — Tidal начинает помечать как abuse → temp ban → permaban за 3-7 дней
- При 50 платных юзерах × 30 треков/нед = ~1500 треков/нед = **~5 аккаунтов в работе одновременно** + 2 резервных
- При росте до 500 юзеров — **~30-50 аккаунтов**
- Бюджет на аккаунты: €15-30/мес на старте, €100-200/мес в стационаре

### 4.2 Модель `TidalAccountPool`

```python
# providers/tidal/pool.py (план)
class TidalAccount:
    id: int
    label: str            # "family-eu-1", "tr-personal-2"
    refresh_token: str    # encrypted at rest
    daily_quota: int = 100
    downloads_today: int = 0
    last_used: datetime
    status: Literal["active", "exhausted", "banned"]
    banned_at: Optional[datetime]

class TidalAccountPool:
    def acquire(self) -> TidalAccount:  # least-recently-used active
    def report_success(self, acc_id: int): self.downloads_today += 1
    def report_failure(self, acc_id: int, http_status: int):
        if http_status in (401, 403): mark_banned
    def reset_daily_quotas(self): ...     # cron daily
```

- Замена `get_valid_tokens()` в `providers/tidal/auth.py`: вместо чтения локального `tokens.json` — pull из пула. Сейчас этот код юзается из TidalClient — отлично инкапсулировано, поменять одну функцию.
- Админ-команды бота: `/add_account <refresh_token>`, `/list_accounts`, `/ban_account <id>`, `/reset_quotas`.

### 4.3 Мониторинг здоровья пула

- Метрика «активных аккаунтов» в Grafana
- Алёрт в личный TG-чат при <2 активных
- Ежедневный отчёт: использование, забанено, осталось квоты

| План | Цена | Что входит |

| **Free** | 0 | 3 трека/день, только 256 kbps (не FLAC), без Shazam, без караоке |

| **Pro** | 399₽/мес | 200 треков/день, Shazam unlimited, DJ-теги, перевод текстов, приоритет в очереди |
| **Lifetime** | 4990₽ | Pro навсегда. Якорь, для энтузиастов |

Эксперимент с ценой через 3 месяца после запуска.

### 5.2 Поток оплаты

```
Юзер → TG /subscribe → выбор плана → ссылка YooKassa →
оплата → webhook → user.subscription_expires_at += 30d → /me видит ✓
```

Стандартная история. Сложный момент — recurring. YooKassa поддерживает, но через сохранение карты юзера. На старте — **разовые платежи + напоминание за 2 дня до окончания**.

## 6. Roadmap по фичам

Каждая фаза = ~1-2 недели работы. Фазы строго последовательны, потому что более поздние зависят от инфры более ранних.

### Фаза 0: что уже есть ✓
- CLI: login, search, download (Tidal lossless), tagging FLAC/M4A
- Provider-plugin архитектура
- yt-dlp провайдеры: YT Music, SoundCloud, Bandcamp
- Synced LRC лирика

### Фаза 1: Pool + FastAPI (1.5 недели)
- `providers/tidal/pool.py` — SQLite-пул аккаунтов
- Замена `tokens.json` на pool в TidalClient
- FastAPI: `/search`, `/download`, `/tasks/{id}`, `/me`, `/auth/telegram`
- ARQ workers
- Docker Compose: api + workers + redis + postgres
- Локальный деплой → smoke test

### Фаза 2: TG bot MVP (1 неделя)
- aiogram 3 бот
- URL → задача → файл
- `/start`, `/help`, `/me`, `/subscribe`
- Webhook от YooKassa в FastAPI → обновление подписки
- Деплой на Hetzner

### Фаза 3: Shazam-режим (3-4 дня)
- `core/recognize.py` с AudD API
- Голосовое/audio в TG → конвертация ffmpeg → AudD → ISRC
- `TidalProvider.search_by_isrc(isrc)` → если найдено → download
- Fallback: title+artist в обычный search

### Фаза 4: Karaoke RU (2-3 дня)
- DeepL API ключ (free tier)
- `core/translate.py`: парсит LRC, переводит блоками
- Параллельный `.ru.lrc` sidecar
- Опция в боте: `/karaoke` toggle

### Фаза 5: Web frontend (1 неделя)
- Vite + React + TanStack Query
- 3 экрана: поиск, очередь, аккаунт
- Login через Telegram Login Widget

### Фаза 6: DJ pipeline (1 неделя)
- librosa BPM detection
- Простой chroma-based key detector
- BPM / INITIALKEY теги в FLAC
- Опциональный Rekordbox XML экспорт

### Фаза 7: Polishing + рост (бесконечно)
- Spotify-провайдер (matching через YT/Tidal)
- Library sync (Tidal favourites)
- «Level up» — пересканить локальные MP3 → найти FLAC
- Discography completer
- Браузер-расширение
- Plex/Jellyfin handoff

**Совокупно фазы 1-6: ~6 недель сольной работы при темпе ~20 ч/нед.** Прод-старт реалистичен через 1.5-2 месяца.

## 7. Юридика и риски

### 7.1 Что нарушает Tidal ToS
- Скачивание контента → формально нарушение, для **юзера** (мы — посредник). 
- Распространение чужой подписки между неавторизованными лицами → серая зона.
- Перепродажа доступа → жёсткое нарушение.

**Митигация:** позиционируем сервис как «личный downloader-инструмент». Юзер не получает напрямую чужой Tidal-аккаунт. Файлы хранятся временно (24ч), потом удаляются.

### 7.2 Что нарушает РФ-закон
- Распространение копирайт-контента без лицензии → ст. 1270 ГК РФ.
- На практике РКН блокирует домены, банк-карты не отменяются.

**Митигация:** ToS чётко определяет, что юзер использует на свой риск; делаем upload/store минимальным; готов план миграции домена.

### 7.3 Что нарушает Hetzner AUP
- Hosting of pirated content → могут отключить сервер.

**Митигация:** на диске НИЧЕГО постоянного — файлы существуют максимум 24ч в temp-папке, не индексируются. Сервер — это API+воркеры, не файлохранилище.

### 7.4 План Б при каждом риске

| Что упало | План Б |
|-----------|--------|
| Tidal все аккаунты разом | Ручной добав новых через бот, при пустом пуле — фоллбек на yt-dlp YT-матч |
| YooKassa закрыла | Включаем Tribute из env, обновляем ссылки в боте |
| Домен `.app` заблочили в РФ | Юзеры из RU идут через бот (TG-инфра) или зеркало |
| Hetzner отключил VPS | Деплой из docker-compose на Vultr за 30 минут, restore DB из B2 |
| Telegram бот забанили | Создаём нового бота, рассылаем юзерам новый @username через email/Boosty |

### 7.5 Что НЕ делаем (намеренно)
- Не публикуем каталог/превью скачанных треков (это уже распространение)
- Не предлагаем re-share файлов между юзерами
- Не сохраняем файлы дольше TTL
- Не логируем что конкретно качал юзер (минимум — только биллинг и события «N скачиваний за день»)

## 8. Метрики

Что меряем с первого дня:

- **MAU**, **conversion** Free → Basic, **retention M1/M3**
- **Average track downloads / user / day**
- **Pool health**: активных аккаунтов, ban rate в неделю, downloads per account
- **Latency**: время от ввода URL до файла
- **Failure rate** по провайдерам (Tidal vs yt-dlp)
- **Стоимость инфры на одного активного юзера в месяц** (главная экономика)

Стек: PostgreSQL events → раз в сутки агрегация → простой дашборд на Grafana.

## 9. Известные неопределённости

- **Точная стоимость одного аккаунта Tidal** в RU-реалиях — не знаю, надо просчитать по факту.
- **Реальная скорость бана** при разумных квотах — узнаем после месяца боевой эксплуатации.
- **Conversion из бесплатных в платные** — оценка 5-10%, но это пальцем в небо.
- **Spotify-matching качество** — известно что spotdl дает ~85% точных матчей, на оставшихся юзеру нужен manual confirm.
- **DeepL free tier 500k chars/мес** — хватит на ~5000 песен. При росте — переход на paid (€8/мес безлимит).
